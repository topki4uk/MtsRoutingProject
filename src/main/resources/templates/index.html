между тремя базами данных

Логика маршрутизации

Как выбирается база данных?

Каждый запрос несёт числовой параметр type. Перед выполнением запроса к БД сервис вычисляет type % 3 и через ThreadLocal устанавливает нужный источник.

Значение type type % 3 DataSourceKey PostgreSQL Порт
0, 3, 6, 9 … 0 PRIMARY db_primary 5432
1, 4, 7, 10 … 1 SECONDARY db_secondary 5433
2, 5, 8, 11 … 2 TERTIARY db_tertiary 5434

REST API

Эндпоинты

Все маршруты доступны по базовому пути /api/data. Полная документация — в Swagger UI.

GET
/api/data?type={n}
Возвращает список записей из базы данных, соответствующей типу. Если записей нет — 404 Not Found.
Query param: type (Integer, required) — определяет целевую БД
POST
/api/data
Сохраняет запись в базу данных, выбранную на основе поля type из тела запроса. Возвращает UUID созданной записи со статусом 201 Created.
Body: DataRecordDto (JSON) — поля записи, включая type
GET
/actuator/health
Spring Boot Actuator health check. Возвращает статус приложения и всех зависимостей.

Запуск за 3 шага

Для запуска нужен только Docker >= 20.10 и Docker Compose >= 2.0.

1
Клонировать репозиторий
git clone https://github.com/topki4uk/MtsRoutingProject.git
2
Запустить через Docker Compose
docker compose up --build
Compose автоматически поднимет три инстанса PostgreSQL и запустит приложение, дождавшись их готовности.
3
Открыть Swagger UI
/swagger-ui.html
